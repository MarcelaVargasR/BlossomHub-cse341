# BlossomHub — Flower Shop REST API
An academic team project (CSE 341) that provides a backend API for managing a flower shop. The application organizes flower products, categories, users, and customer orders.
## Features
- CRUD operations for flowers and categories
- User and order management, including order status updates
- GitHub OAuth authentication using Passport.js
- Request validation with Joi and centralized error handling
- Interactive API documentation with Swagger
## Tech stack
JavaScript, Node.js, Express.js, MongoDB Atlas, Mongoose, Joi, Passport.js, Swagger. Jest and Supertest are included in the development dependencies.
Project structure
- routes/: API endpoints
- controllers/: request handling and application logic
- models/: database models
- middleware/ and validators/: authentication, error handling and validation
- utils/: database connection and Swagger configuration
- test/: API tests
